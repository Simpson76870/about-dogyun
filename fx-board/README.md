# 오늘의 진짜 정보판 — 원/달러 · 원/100엔

매일 실제로 바뀌는 값(원/달러, 원/100엔 환율)을 보여주고, 데이터가 오지 않을 때도
정직하게 마지막 정상값을 유지하며 상태를 설명하는 정보판입니다.

- 데이터 출처: [Frankfurter API](https://www.frankfurter.dev/) (ECB 기준환율) — 로그인·API 키·CAPTCHA 없음
- 매일 기록: GitHub Actions가 KST 날짜 기준 하루 한 번만 `data/history.json`에 추가
- 화면: 정적 페이지(`index.html`) 하나로 동작, 별도 백엔드 없음

## 배포 방법 (GitHub Pages)

1. 이 폴더 전체를 새 GitHub 저장소에 푸시합니다.
2. 저장소 **Settings → Actions → General → Workflow permissions**에서
   **"Read and write permissions"**를 선택하고 저장합니다.
   (환율 기록을 커밋하려면 Actions가 쓰기 권한을 가져야 합니다.)
3. 저장소 **Settings → Pages**에서 배포 브랜치를 `main` / 루트(`/`)로 지정합니다.
4. **Actions** 탭에서 `매일 환율 수집` 워크플로를 한 번 **수동 실행(Run workflow)**해서
   `data/history.json`에 첫 기록을 만들어 둡니다. (자동 실행은 매일 UTC 21:30, KST 06:30에 동작)
5. 다음날 이후 다시 수동 실행하거나 자동 실행을 기다리면 두 번째 기록이 쌓여
   "어제 대비 변화"가 채워집니다.

## 짧은 확인 방법 (초안 — 실제 배포 주소로 바꿔서 제출하세요)

1. 위치: `https://<사용자명>.github.io/<저장소명>/`
2. 행동: 페이지를 열기만 하면 됨 (추가 클릭 불필요) — 값이 자동으로 조회됨
3. 통과 모습: 원/달러·원/100엔 값·단위·출처·원천 시각·조회 시각이 각 카드에 표시되고,
   "실패 상태 미리보기" 버튼을 누르면 해당 실패 문구로 바뀌었다가 "정상으로 복구" 버튼으로
   되돌아옴
4. 안 될 때 모습: 값 카드가 흐릿하게(회색) 바뀌고 "마지막 정상값 · N일 기록 유지 중" 문구와
   함께 실패 종류(401/403, 호출 제한, 오프라인, 형식 변경)가 배지로 표시됨

## 알아둘 점 / 직접 확인 필요

- 이 코드의 "실패 상태 미리보기"는 **이 프로젝트 안에서 직접 합성한 가짜 실패**입니다.
  과제 플랫폼이 제공하는 공식 fixture 꾸러미(ZIP)·SHA-256 목록·판정 계약이 있다면,
  그 공식 자산과 이 페이지의 동작이 정확히 일치하는지 반드시 직접 대조하세요. 저는 그
  플랫폼 전용 다운로드 자산에 접근할 수 없어서 일반적인 형태로만 구현했습니다.
- GitHub Actions 자동 실행 시각은 예시(UTC 21:30)입니다. 필요하면
  `.github/workflows/fetch-rates.yml`의 `cron` 값을 조정하세요.
- ECB 기준환율은 주말·휴장일에는 갱신되지 않습니다. 이 경우는 "실패"가 아니라
  "그날은 새 값이 없는 정상 상태"이므로, 페이지는 마지막 정상값을 그대로 보여줍니다.
