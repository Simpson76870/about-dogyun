# BR-A 기록 갱신 장치

로컬 JSON 기록으로부터 리추얼 숫자 요약과 날짜·근거가 붙은 문단 후보를 생성합니다. 외부 API, 로그인, API 키가 필요 없습니다.

## 실행 방법
1. Python 3.10 이상을 설치하고 이 폴더를 복사합니다.
2. `input/ritual_records.json`을 최신 기록으로 갱신합니다. 동료 실명·연락처·비밀값은 넣지 않습니다.
3. 터미널에서 이 폴더로 이동해 `python generate.py`를 실행합니다. 결과는 `output/latest_result.json`에 저장됩니다.

입력·출력 경로 지정: `python generate.py --input input/ritual_records.json --output output/latest_result.json`

## 입력과 출처
현재 포함한 최소 데이터에서 아침 49회와 마무리 48회는 2026-10-27에 제공된 리추얼 화면의 집계이고, 세부 내용은 같은 날짜의 아침 기록 1건입니다. 출석·제출 통계는 원본 수치가 없어 포함하거나 추정하지 않았습니다.

## 재현성 확인
- 같은 폴더에서 `python generate.py`를 두 번 실행하고 출력된 SHA256이 같은지 확인합니다.
- 폴더 전체를 새 위치로 복사한 뒤 실행을 반복합니다.
- 결과는 후보 문장과 근거일 뿐입니다. 자동 게시 기능은 없으며, 사용자가 사실 확인 후 승인한 문장만 사이트에 반영합니다.
- 공개 자료에서 타인의 실명, 연락처, 비밀번호, 토큰, API 키를 제거합니다.
